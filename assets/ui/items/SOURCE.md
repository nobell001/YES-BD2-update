# Item icons

The sale-item icons in this folder (64×64 PNG, resized) come from BD2DB
(https://browndust2-db.souseha.com/), which hosts the game's own item art
(`https://image-bd2db.souseha.com/new_items/<itemId>.webp`).

The artwork belongs to the game's publisher (Brown Dust 2, NEOWIZ). It is
used only to show which item the trade task sells. `index.json` maps each
item's Simplified Chinese name (as the game client shows it) to its file.
